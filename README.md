# 🏏 IPL Score Analysis System

A Java-based IPL Score Analysis System that reads match and ball-by-ball delivery data from CSV files and provides useful cricket statistics through a console-based menu.

## 📌 Project Overview

This project analyzes IPL match data using Java, Object-Oriented Programming (OOP), CSV File Handling, Collections, and data analysis techniques.

The system reads:

- `matches.csv` - IPL match information
- `deliveries.csv` - Ball-by-ball delivery information

and generates different IPL statistics.

## 🚀 Features

1. Total Runs By Team
2. Top Batsman
3. Most Sixes
4. Team Wins
5. Player Statistics
6. Match Winners
7. Highest Individual Score
8. Most Fours
9. Top 10 Batsmen
10. Top 10 Bowlers
11. Season Analysis
12. Player Strike Rate
13. Bowler Economy Rate
14. Team Performance
15. IPL Dashboard
